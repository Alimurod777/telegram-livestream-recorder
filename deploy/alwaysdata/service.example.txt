Alwaysdata panel: Advanced > Services > Add a service

Name: telegram-livestream-recorder
Command: bash /home/telegramdata3/telegram-livestream-recorder/scripts/start_alwaysdata.sh bot
Working directory: leave empty (recommended); alternatively telegram-livestream-recorder
Environment variables: PYTHONUNBUFFERED=1 (optional; launcher already uses -u)
Monitoring command: leave empty

The script sets its own working directory and uses this project's venv.
Do not put /home/telegramdata3/... into the Working directory field: this panel
prefixes the account home and would produce /home/telegramdata3/home/telegramdata3/...
The absolute script path in Command is correct; keep it as shown above.
For another Alwaysdata account/repository path, replace the absolute path above.
The bot uses outbound Telegram long polling; it does not listen on an HTTP port.

Prepare .env and venv before enabling. Run only one service per bot token.
Use the service's Logs and Restart controls to inspect/manage it.
Restart can end active captures: first use /stop all and wait for delivery.
Full setup, updates and troubleshooting: docs/ALWAYSDATA.md
